# 怎么编写 README

**README.md** 是仓库打开后默认展示在首页的说明文档，用 **Markdown** 编写。它是别人了解你项目的"第一张名片"。

一份好的 README 通常包含：

- **项目简介**：一句话说明这个项目是做什么的。
- **安装方法**：环境依赖、如何安装。
- **使用方法**：怎么运行、示例代码。
- **许可证 / 贡献方式**：指向 LICENSE 或说明如何参与。

## 常用 Markdown 语法

````markdown
# 一级标题
## 二级标题
- 列表项
**加粗**、*斜体*
`行内代码`
[链接文字](网址)
![图片描述](图片地址)
```
代码块
```
````

还有一些常用的写法：

```markdown
| 表头 | 表头 |
| --- | --- |
| 单元格 | 单元格 |

- [x] 已完成任务
- [ ] 待办任务

> 引用
```

创建方法：新建仓库时勾选 "Add a README file"，或之后点 **Add file → Create new file**，文件名写 `README.md`。

## 一个简单的 README 模板

可以从下面这个大纲开始，填入你自己的内容：

```markdown
# 项目名称

一句话说明：这个项目是做什么的？

## 安装方法

如何安装依赖、完成配置。

## 使用方法

如何运行，附上示例命令。

## 参与贡献

其他人可以怎样参与，以及许可证链接。
```

!!! tip "图片与徽章"
    - 想放图片：把图片放进仓库（例如 `images/` 文件夹）用相对路径引用；或者把图片拖进某个 Issue 的评论框，复制自动生成的链接。
    - 用 [shields.io](https://shields.io) 生成一行状态徽章（构建状态、许可证、下载量……），会让 README 看起来更专业。
