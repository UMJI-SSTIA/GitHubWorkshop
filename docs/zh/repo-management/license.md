# 什么是许可证（License）

**License（许可证）** 是一份法律声明，规定别人可以怎样使用你的代码。它是开源项目里很重要的一部分：

| 许可证 | 特点 | 适用场景 |
| --- | --- | --- |
| **MIT** | 最宽松，别人可以随便用、改、商用，只需保留版权声明 | 大多数个人项目 |
| **Apache 2.0** | 宽松 + 明确专利授权 | 企业、需要专利保护 |
| **GPL** | "传染性"强，用了它就必须同样开源 | 希望衍生项目也开源 |
| **BSD** | 类似 MIT，条款略多 | 学术类项目 |
| **Unlicense** | 放弃所有权利，代码进入公有领域 | 希望代码完全无限制使用 |

要点：

- **没有 license** 是默认"保留所有权利"，别人**不能合法地**复制或修改你的代码。
- 添加方法：创建仓库时直接选择，或之后点 **Add file → Create new file**，把文件名写成 `LICENSE.txt`，GitHub 会自动提供模板选择。
- GitHub 按模板生成许可证文件时，会带一行占位的版权信息（`[year] [fullname]`），记得把它替换成你自己的名字和当前年份。

!!! tip
    不知道选哪个？[choosealicense.com](https://choosealicense.com) 由 GitHub 维护，回答几个简单问题就能帮你推荐一个合适的许可证。

!!! note "该怎么选？"
    拿不准的话：个人项目和课程作业选 **MIT**；在意专利权选 **Apache 2.0**；希望衍生项目也保持开源选 **GPL**。许可证之后也可以换——直接替换 `LICENSE` 文件即可（正规项目里如果有很多贡献者，换之前需要所有贡献者同意）。
