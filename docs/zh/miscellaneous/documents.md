# 文档资料

学完本 workshop 之后，如果想继续深入，可以看看这些官方文档和延伸阅读：

## 官方文档

- [GitHub Docs](https://docs.github.com/en) —— GitHub 官方文档，覆盖仓库、Pull Request、Actions、API 等方方面面。

## 延伸阅读

- [GitHub 漫游指南](https://github.phodal.com/#/) —— 一本关于如何在 GitHub 上做好项目的中文电子书，观察了用户在 GitHub 上的行为，有很多有趣的发现。
- [Pro Git](https://git-scm.com/book/) —— 经典的免费 Git 教材，从基础一直讲到内部原理。
- [GitHub Skills](https://skills.github.com) —— GitHub 官方的免费互动课程，直接在仓库里边做边学。
