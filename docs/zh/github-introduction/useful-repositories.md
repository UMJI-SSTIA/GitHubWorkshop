# 一些有用的仓库

以下是一些对学习和入门非常有帮助的公开仓库，可按兴趣搜索并实践：

除了这份清单，[GitHub Explore](https://github.com/explore) 和 [GitHub Trending](https://github.com/trending) 也是每天发现新项目的好去处。

**学习类**

- [free-programming-books-zh](https://github.com/justjavac/free-programming-books-zh_CN)：免费的中文编程书籍合集。
- [freeCodeCamp/freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp)：开源的免费编程学习课程与练习平台。
- [TheAlgorithms](https://github.com/TheAlgorithms)：用各种语言实现的数据结构与算法合集。
- [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x)：用你喜欢的语言从零实现各种技术（数据库、操作系统、编译器……）。
- [every-programmer-should-know](https://github.com/mtdvio/every-programmer-should-know)：每个程序员都应该知道的知识清单。

**资源合集类（Awesome 系列）**

- [awesome](https://github.com/sindresorhus/awesome)：各种主题的"精选资源清单"总入口。
- **awesome-chinese** / 各类 `awesome-xxx`：按主题整理的优质资源列表，非常适合按图索骥。

**工程/工具类**

- [github/gitignore](https://github.com/github/gitignore)：各种语言和环境的 `.gitignore` 模板合集。
- [microsoft/vscode](https://github.com/microsoft/vscode)：微软的开源编辑器 VS Code 源码，适合阅读大型项目。
- [vuejs/vue](https://github.com/vuejs/vue)、[facebook/react](https://github.com/facebook/react)：主流前端框架源码。

## 实践环节

1. 搜索一个感兴趣的话题
2. 找到一个维护良好的仓库
3. 下载一些有用的代码
