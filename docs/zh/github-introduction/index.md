# 走近 GitHub

<figure markdown="span">
  ![GitHub 标志](../../assets/images/GitHub-Mark.png){ width="300" }
  <figcaption> GitHub Logo: Octocat </figcaption>
</figure>

GitHub 是全球最大的代码托管与协作平台，也是大多数开发者进入开源世界的入口。在本部分中，你将了解 GitHub 与开源平台是什么，注册自己的账号，并学会如何在 GitHub 上搜索、判断和下载仓库。

## 开始之前

- 一台能上网的电脑和浏览器；
- 一个能正常收信的邮箱（注册 GitHub 账号要用）；
- 本章节大约需要 30 分钟，[下一章节](../repo-management/index.md)大约需要 60 分钟。

## 你将学到

- [GitHub 是什么](what-is-github.md)：GitHub 与 Git 的关系，以及你能在 GitHub 上找到的意想不到的内容。
- [开源平台](open-source-platforms.md)：开源平台是什么，以及 GitHub 在其中有什么优势。
- [注册 GitHub 账号](register-account.md)：动手实践，一步步创建自己的账号。
- [在 GitHub 上搜索](searching-on-github.md)：找到有用的仓库，并用常用指标评估它们。
- [判断仓库的维护状态](repository-status.md)：用 Insights 判断一个项目是否仍在活跃维护。
- [下载源代码](download-code.md)：下载 ZIP、用 Git 克隆，或者下载发行版。
- [一些有用的仓库](useful-repositories.md)：一份值得探索的仓库清单，并附实践环节。
