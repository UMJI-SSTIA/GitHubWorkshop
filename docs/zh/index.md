# GitHub Workshop

<div style="text-align: center; margin: 2rem 0;">
  <img src="../assets/images/GitHub-Mark.png" alt="GitHub 标志" style="width: 160px; max-width: 40%;">
</div>

这是一个由 SSTIA 制作、面向初学者的 GitHub 入门 Workshop。课程分为两部分：先认识 GitHub 与开源社区，学习搜索、判断和下载仓库；再动手创建和维护仓库，体验完整的开源协作流程。

完成课程后，你将能够：

- 查找并判断一个开源项目是否值得使用；
- 创建仓库，使用 Git 提交和推送代码；
- 通过 Fork、Issue 和 Pull Request 参与协作；
- 编写 README、选择开源许可证，并用 GitHub Pages 发布网站。
