# GitHub Workshop

GitHubWorkshop 内容摘要

GitHubWorkshop 是一套由 USSTIA 制作、面向 GitHub 初学者的workshop。课程从 GitHub 和开源的基本概念出发，逐步引导学习者完成仓库查找、下载、创建、维护、协作贡献和网站发布，形成一条完整的 GitHub 入门实践路径。

课程主要内容
第一部分：认识 GitHub 与寻找项目
- 介绍 GitHub、Git 和开源平台的基本概念。
- 对比 GitHub、GitLab、Gitee、Bitbucket 等代码托管平台。
- 说明 GitHub 在社区规模、协作机制、工具生态和行业应用方面的优势。
- 指导学习者注册 GitHub 账号。
- 讲解如何使用搜索功能寻找项目。
- 从 Star、Fork、Issue、提交记录、贡献者、License、README 和 Release 等维度评价仓库。
- 通过 Insights、Commits 和 Network 判断项目是否仍在维护。
- 区分 Download ZIP、git clone 和下载 Release 三种获取项目的方式。
- 推荐 freeCodeCamp、TheAlgorithms、Awesome 系列、VS Code、React 等学习资源。
第二部分：使用仓库与参与协作
- 创建公开或私有仓库，配置 README、.gitignore 和 License。
- 使用网页上传文件，或通过 Git 完成 add、commit 和 push。
- 介绍 MIT、Apache 2.0、GPL、BSD 等常见开源许可证。
- 解释 Fork 的含义及其适用场景。
- 演示标准开源贡献流程：
  Fork → Clone → 创建分支 → 修改并提交 → Push → Pull Request → Review
- 说明如何提交高质量 Issue，以及如何根据审查意见持续更新 PR。
- 提醒谨慎使用 git add -f，避免误提交被 .gitignore 排除的文件。
- 介绍 GitHub 网页端的新建、编辑、上传和删除文件功能。
- 讲解 README 的作用、基本结构和常用 Markdown 语法。
- 指导使用 GitHub Pages 将仓库发布为静态网站。
  
总结
这个wksp的核心目标，是帮助初学者完成从“认识 GitHub”到“能够使用 GitHub 参与实际项目”的过渡。学习结束后，参与者应能独立寻找并判断开源项目、创建和维护仓库、正确选择许可证、使用 Git 完成基本版本管理、通过 Issue 和 Pull Request 参与协作，并使用 GitHub Pages展示项目。

当前课程主体已经覆盖完整的入门流程，但部分首页和 README 仍保留早期 Workshop Template 的模板描述，与实际 GitHub Workshop 课程内容并不完全一致。
