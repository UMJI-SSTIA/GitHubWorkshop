# Some Useful Repositories

The following public repositories are very useful for learning and getting started. Search for and explore them according to your interests:

Besides this list, [GitHub Explore](https://github.com/explore) and [GitHub Trending](https://github.com/trending) are two good places to discover new projects every day.

**Learning**

- [free-programming-books-zh](https://github.com/justjavac/free-programming-books-zh_CN): A collection of free Chinese programming books.
- [freeCodeCamp/freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp): An open-source platform offering free programming courses and exercises.
- [TheAlgorithms](https://github.com/TheAlgorithms): A collection of data structures and algorithms implemented in various programming languages.
- [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x): Implement things from scratch (databases, operating systems, compilers, ...) in your favorite language.
- [every-programmer-should-know](https://github.com/mtdvio/every-programmer-should-know): A curated list of things every programmer should know.

**Resource Collections (Awesome Lists)**

- [awesome](https://github.com/sindresorhus/awesome): A central collection of curated resource lists covering a wide variety of topics.
- **awesome-chinese** / various `awesome-xxx` repositories: Curated resource lists organized by topic, making it easy to follow a trail of useful resources.

**Engineering / Tools**

- [github/gitignore](https://github.com/github/gitignore): A collection of `.gitignore` templates for various languages and environments.
- [microsoft/vscode](https://github.com/microsoft/vscode): The source code of Microsoft's open-source editor, VS Code; suitable for studying a large-scale project.
- [vuejs/vue](https://github.com/vuejs/vue) and [facebook/react](https://github.com/facebook/react): The source code of mainstream front-end frameworks.

## Practice

1. Search for a topic that interests you.
2. Find a well-maintained repository.
3. Download some useful code.
