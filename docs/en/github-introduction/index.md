# Towards GitHub

</figure>


GitHub is the world's largest code hosting and collaboration platform, and the gateway to the open-source world for most developers. In this part, you will learn what GitHub and open-source platforms are, register your own account, and learn how to search for, evaluate, and download repositories on GitHub.

## Before you start

- a computer with a browser and internet access;
- an email address you can check (needed to register a GitHub account);
- about 30 minutes for this part, plus 60 minutes for [the next one](../repo-management/index.md).

## What you will learn

- [What is GitHub](what-is-github.md): the relationship between GitHub and Git, and the surprising things you can find on GitHub.
- [Open-source platforms](open-source-platforms.md): what open-source platforms are, and why GitHub stands out among them.
- [Register a GitHub account](register-account.md): a hands-on exercise — create your own GitHub account step by step.
- [Searching on GitHub](searching-on-github.md): find useful repositories and evaluate them with common metrics.
- [Determine a repository's status](repository-status.md): use Insights to tell whether a project is still actively maintained.
- [Download source code](download-code.md): download a ZIP, clone with Git, or grab a release package.
- [Useful repositories](useful-repositories.md): a curated list of repositories worth exploring, with a hands-on exercise.
