# Documentations

Official documentation and recommended reading if you want to go deeper after the workshop:

## Official documentation

- [GitHub Docs](https://docs.github.com/en) — the official documentation maintained by GitHub, covering everything from repositories and pull requests to Actions and the API.

## Recommended reading

- [GitHub 漫游指南](https://github.phodal.com/#/) — a Chinese ebook on how to build a good project on GitHub. It explores how users behave on GitHub and shares many interesting observations.
- [Pro Git](https://git-scm.com/book/) — the classic free book on Git, from the basics to the internals.
- [GitHub Skills](https://skills.github.com) — free interactive courses that teach Git and GitHub by doing, right inside a repository.
